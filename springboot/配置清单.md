# 开罗论坛 · 自托管部署配置清单（精简版）

本文档是「脱离作者 ns-manage 外部 Dubbo 服务、独立运营」的落地清单。已根据论坛前端 `vue-ui` 的实际接口用量做精简：**只保留前端真正用到的鉴权能力**，去掉角色/权限/组织/反馈/捐赠等管理端功能。

> 核心思路：新增 `bbs-auth` 模块，本地实现论坛前端实际依赖的 7 个 Dubbo 接口，
> 让 `bbs-rest` / `bbs-user` / `bbs-article` 的 `@DubboReference` 指向我们自己的 Provider。

---

## 一、需要你自己准备的基础设施

| 组件 | 默认地址（已写入代码） | 说明 |
|------|----------------------|------|
| Zookeeper | `127.0.0.1:2181` | Dubbo 注册中心，**4 个模块必须指向同一台** |
| Redis | `127.0.0.1:6379`（无密码） | SSO token / 验证码 存储 |
| MySQL | `127.0.0.1:3306` | 两个库：`open_bbs`（论坛）+ `ns_auth`（鉴权） |

> ⚠️ **关键**：原工程 `bbs-rest/bbs-user/bbs-article` 的配置指向作者服务器
> （ZK `47.109.0.224:2181`、Redis `8.137.106.178:6222`）。若继续连作者 ZK，会与作者仍在运行的
> ns-manage Provider 发生服务发现冲突。**请务必全部改成你自己的 ZK/Redis**（见下节）。

> MongoDB **不再需要**（闲聊群组已剔除）。

---

## 二、需要手动修改的配置（4 处 application.yml）

把下面 4 个文件里的 `dubbo.registry.address` 与 `spring.data.redis` 改成**你自建的地址**，且**四个模块保持一致**：

| 模块 | 文件 | 需要改的项 | 现有值（需替换） |
|------|------|-----------|----------------|
| bbs-rest | `bbs-rest/src/main/resources/application.yml` | `dubbo.registry.address`、`spring.data.redis.*` | `47.109.0.224:2181` / `8.137.106.178:6222` |
| bbs-user-service | `bbs-user/bbs-user-service/src/main/resources/application.yml` | 同上 | 同上 |
| bbs-article-service | `bbs-article/bbs-article-service/src/main/resources/application.yml` | 同上 | 同上 |
| bbs-auth（新增） | `bbs-auth/src/main/resources/application.yml` | 已按 `127.0.0.1` 预设，按需调整 | — |

同时确认各模块 MySQL：
- `bbs-user-service`、`bbs-article-service` 连 `open_bbs` 库（账号/密码按你本地改）。
- `bbs-auth` 连 `ns_auth` 库。

## 三、建库脚本

| 数据库 | 脚本 | 说明 |
|--------|------|------|
| `open_bbs` | `db备份/open_bbs.sql` | 论坛业务库（文章/评论/点赞等），按需导入 |
| `ns_auth` | `bbs-auth/db/ns_auth.sql` | **鉴权库（新增，仅 4 张表），必导** |

导入方式：
```bash
mysql -uroot -p < db备份/open_bbs.sql
mysql -uroot -p < bbs-auth/db/ns_auth.sql
```

## 五、编译与启动

```bash
# 在 springboot 根目录
mvn clean install -DskipTests
```

启动顺序（先中间件，再 Provider，最后网关）：

```bash
# 1. 启动 ZK / Redis / MySQL

# 2. 鉴权服务（新增，先启动）
java -jar bbs-auth/target/bbs-auth.jar

# 3. 业务 Provider
java -jar bbs-user/bbs-user-service/target/bbs-user-service.jar
java -jar bbs-article/bbs-article-service/target/bbs-article-service.jar

# 4. REST 网关
java -jar bbs-rest/target/bbs-rest.jar
```

> `dubbo.consumer.check=false` 已开启，Provider 未就绪也能启动；但走到登录/鉴权/上传时，
> 对应 Provider 必须已注册，否则报「No provider」。

## 六、端口与 Dubbo 服务清单

| 服务 | HTTP 端口 | Dubbo 端口 | 说明 |
|------|----------|-----------|------|
| bbs-rest | 7010 | 22001 | 消费者，不注册 |
| bbs-article-service | 7011 | 22002 | `ArticleService` 等 |
| bbs-user-service | 7013 | 22003 | `UserLevelService` 等 |
| **bbs-auth（新增）** | 7014 | 22004 | 见下方 7 个服务 |

`bbs-auth` 注册的 7 个 Dubbo 服务（前端实际依赖）：
- `UserService` —— 登录/注册/登出/SSO token/用户信息/改密/绑定邮箱手机
- `UrlAccessRightService` —— 管理端路径权限（超管放行，非超管拒绝管理接口）
- `FileService` —— 文件上传（本地磁盘，替代七牛云）
- `NotifyService` —— 通知（未读数量/列表/已读）
- `VisitService` —— 访问记录
- `MailService` / `SmsService` —— 验证码发送（可选，未配置则仅记录日志）

---

## 七、可选外部服务（不配置也能跑）

| 能力 | 默认行为 | 真实生效需配置 |
|------|---------|---------------|
| 文件上传 | 存本地磁盘 `auth.file-storage-path`（默认 `./uploads`），经 `auth.file-url-prefix` + `/static/**` 访问 | 无（已本地化） |
| 邮件验证码 | 打印日志，验证码写 Redis | 配置 `spring.mail.*`（需补 application.yml 邮件块） |
| 短信验证码 | 打印日志，验证码写 Redis | 配置 `auth.sms.*` 阿里云 AK 并接入 `SmsServiceImpl` |

## 八、关键实现说明

- **登录态**：`login/register` 生成 UUID token，将 `UserSsoDTO`（含 roles）JSON 存 Redis `ns:sso:token:{token}`，TTL 7 天。
- **密码**：`SHA256(salt + 明文)`，盐随机 16 位 hex（`PasswordUtils`）。种子超管盐值固定 `a1b2c3d4e5f6a7b8`。
- **超管判定**：`UserSsoDTO.roles` 中 `grade == NS_SUPER_ADMIN_ROLE`（由 `is_admin` 标记注入），前端 `App.vue` 据此显示管理入口。
- **管理接口权限**：`checkUrlAccess` 规则为「未登录拒绝 → 超管放行 → 非超管拒绝命中管理路径的请求」。
  管理路径硬编码在 `UrlAccessRightServiceImpl.ADMIN_PATHS`（文章审核/置顶、标签/资源增删改上传）。
